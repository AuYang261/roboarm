## 推理流程

1. 从 :5002 / :5003 接收最新帧，维护 latest_top_jpeg / latest_wrist_jpeg
2. 两路帧均非空时触发推理：
   - cv2.imdecode 解码 JPEG → BGR ndarray (480, 640, 3)
   - 传入 Being-H05 推理引擎
3. 推理输出 (16, 5) arm_joint + (16, 1) gripper
4. 构造上述 JSON → sendto(192.168.2.5:5000)
5. sequence_id 递增

### 各模块详解

#### server/__init__.py
包入口，文档说明四个模块的功能和所属包结构。

#### server/udp_receiver.py — 视频流接收模块

**设计原则**：与客户端 `client/udp_receiver.py` 保持一致的接口风格。

**核心类**：

| 类 | 功能 |
|----|------|
| `FrameReceiver` | 单路 UDP 接收器。绑定一个端口 → `recv()` 返回原始字节 → `recv_frame()` 解码为 BGR ndarray |
| `DualReceiver` | 双路接收管理器。包装两个 FrameReceiver（:5002/:5003），`recv_both()` 排空每路队列取最新帧 |

**关键实现**：
```python
class FrameReceiver:
    def __init__(self, host="0.0.0.0", port=5002, timeout_ms=10):
        self._sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        self._sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        self._sock.settimeout(timeout_ms / 1000.0)  # 非阻塞
        self._sock.bind((host, port))

    def recv(self) -> bytes | None:
        try: return self._sock.recvfrom(65536)[0]
        except socket.timeout: return None

    def recv_frame(self) -> np.ndarray | None:
        data = self.recv()
        if data is None: return None
        return cv2.imdecode(np.frombuffer(data, np.uint8), cv2.IMREAD_COLOR)
```

**DualReceiver.recv_both()** 采用"排空队列取最后一帧"策略：
- 每路持续 recv 直到返回 None（timeout）
- 保留最后一次收到的 JPEG 数据
- 解码为 BGR ndarray 返回
- 这确保推理始终使用最新帧，不会堆积延迟

#### server/inference_engine.py — 推理引擎模块

**核心类**：`InferenceEngine`

**状态估计策略**（关键设计决策）：

客户端只发送视频流，不发送关节状态。但 Being-H05 模型需要状态输入。解决方案：

1. **初始化**：从 checkpoint 的 `*_metadata.json` 中读取每关节的 mean 值作为初始状态
2. **推理后更新**：`state ← predicted_action[0]`（取 16 步预测的第 1 步）
3. **可行性**：Koch follower 格式中 action = 绝对关节位置命令，因此预测值即是当前状态的有效估计

**公开方法**：

| 方法 | 功能 |
|------|------|
| `__init__(checkpoint, ...)` | 加载 BeingHPolicy 模型，初始化状态 |
| `infer(top_bgr, wrist_bgr) → dict` | 单帧推理，返回 `{"arm_joint_position": list, "gripper_position": list, "inference_time_ms": float}` |
| `set_state(state_6d)` | 从外部设置状态（如客户端将来发送状态反馈） |
| `get_state() → np.ndarray` | 读取当前估计状态 |
| `reset_state()` | 重置为 metadata mean 值 |

**图像处理**：
- 输入 BGR（OpenCV 格式）→ `frame[..., ::-1]` 转为 RGB
- 后续由 BeingHPolicy 内部 `image_transform` 处理：Resize(224) → CenterCrop(224) → ToTensor → ImageNet 归一化

**配置参数**：
```python

    data_config_name="koch_follower",                 # 数据配置
    dataset_name="koch_posttrain",                    # 元数据组
    embodiment_tag="koch",                            # 机器人实施例

    device="cuda",                                    # 推理设备
    enable_rtc=False,                                 # 服务器端禁用 RTC（客户端处理）
    metadata_variant=None,                            # 归一化统计量变体
)
```

#### server/server_main.py — 主入口

**核心类**：`InferenceServer`

**主循环流程**：
```
while running:
    1. DualReceiver.recv_both()       → 取双路最新帧
    2. if 两帧均非空:
         InferenceEngine.infer()      → 推理
         ActionSender.send_json()     → 发送动作
         sequence_id++
    3. sleep(剩余时间)                  → 保持目标推理速率（默认 ~15Hz）
```

**启动流程**：
1. 初始化 DualReceiver（bind :5002, :5003）
2. 初始化 InferenceEngine（加载 Being-H05 模型，~22s）
3. 初始化 ActionSender
4. 等待双路视频流就绪（最长等待 30s）
5. 进入主循环

**优雅退出**：注册 SIGINT/SIGTERM 信号处理器，确保断开所有 socket 和设备。
